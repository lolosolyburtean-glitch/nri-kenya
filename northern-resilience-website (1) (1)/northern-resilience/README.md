# Northern Resilience Initiatives — Clean Website

A cleaned, consistent, and photo-ready version of the organization website.

## What was fixed
- Corrected spelling to **Northern Resilience Initiatives** everywhere
- Removed all broken / duplicated HTML
- Unified header and footer across every page
- Added the real organization logo
- Integrated community photos and the water-access video
- Made content easy to edit (clear structure, simple HTML)
- Kept Netlify Forms ready
- Added responsive mobile menu
- Modern, clean design matching the logo colours

## Pages
- `index.html` — Homepage with video hero + community photos
- `about.html` — Who we are + values + group photos
- `programs.html` — Three focus areas + water story
- `impact.html` — Accountability + resources placeholders
- `get-involved.html` — Partnership form + landscape photo
- `contact.html` — Contact form + phone number
- `privacy.html` — Privacy draft
- `thank-you.html` — Form success page

## How to edit content
1. Open any `.html` file in a text editor (VS Code, Notepad++, etc.)
2. Look for the text you want to change (headings, paragraphs, etc.)
3. Save the file
4. Refresh the page in your browser

## How to add / replace photos
All images live in the `assets/` folder:
- `logo.png` — organization logo
- `community-meeting-1.webp` / `community-meeting-2.webp` — community discussions
- `about-bg.webp` — group photo
- `impact-bg.webp` — community dialogue
- `programs-bg.webp` — women collecting water
- `involved-bg.jpg` — landscape
- `hero-video-web.mp4` — short video used on homepage

Replace any file with a new one of the same name (or update the `src` path in the HTML).

## Deploy on Netlify
1. Drag the entire `northern-resilience` folder into Netlify
2. Enable form detection
3. Set up form notifications
4. Replace `YOUR-DOMAIN-HERE` in `robots.txt` and `sitemap.xml`
